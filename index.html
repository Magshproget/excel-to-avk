📋 Як завантажити підготовлений файл в АВК-5:

  1. Спосіб 1 (Рекомендований: вбудований імпорт .txt через Alt+F3):
    Натисніть зелену кнопку «1. Вбудований імпорт АВК-5 (.txt для Alt+F3)».
    В АВК-5 у вікні Локального кошторису натисніть «Створення» ➔ «Внесення групи рядків із текстового файлу (Alt+F3)» і виберіть збережений файл. (Створено точно за форматом експорту вашої версії АВК з міткою :Л*).
  2. Спосіб 2 (Вбудований імпорт .xls через Shift+M):
    Натисніть синю кнопку «2. Вбудований імпорт АВК-5 (.xls для Shift+M)».
    В АВК-5 виберіть «Створення» ➔ «Внесення групи рядків із файлу у форматі XLS (Shift+M)».
  3. Спосіб 3 (Через зовнішню програму Rasch_290):
    Натисніть сіру кнопку «3. Для програми Rasch_290 (.xls)».
    У програмі Rasch_290 натисніть «Утилиты» ➔ «ИБД..» ➔ «материалов из прайса (Ctrl+D)». Файл тепер у форматі .xls (який вона відразу бачить) і містить точну назву колонки Количество.
