# Конвертер матеріалів з Excel для АВК-5

Програма для автоматичного перетворення складських відомостей, прайс-листів та інвентаризацій з Excel у формат, придатний для імпорту в програмний комплекс АВК-5 (або для утиліти Rasch_290).

## Як використовувати

### Варіант 1. Швидкий запуск без встановлення (у браузері)
Найпростіший спосіб для роботи на будь-якому комп'ютері з Windows 10:
1. Відкрийте файл `index.html` подвійним кліком (відкриється у браузері Microsoft Edge або Google Chrome).
2. Перетягніть вихідний файл Excel (.xlsx, .xls) або CSV у вікно.
3. Програма автоматично знайде назви, одиниці виміру, кількості та ціни.
4. Натисніть кнопку "Завантажити для АВК-5 (.xlsx)" або "Завантажити під Rasch_290 (.xlsx)".
5. Отриманий файл імпортується в АВК-5 за кілька секунд.

Файл працює повністю автономно (офлайн) без підключення до Інтернету.

### Варіант 2. Програма на Python (з графічним вікном)
1. Запустіть файл `app_gui.py`:
   ```bash
   python app_gui.py
   ```
2. Оберіть файл через кнопку "Огляд файлу".
3. Перевірте знайдені позиції та натисніть "Зберегти готовий файл для АВК-5".

### Варіант 3. Збірка в окремий .exe файл для Windows
Якщо потрібно отримати один автономний файл `Конвертер_АВК.exe` для робочого столу:
1. Запустіть файл `build_exe.bat` на комп'ютері з Windows.
2. Готовий файл з'явиться у папці `dist/Конвертер_АВК.exe`.

## Порядок імпорту файлу в АВК-5
1. Відкрийте ПК АВК-5.
2. Перейдіть у потрібну будову -> "Локальний кошторис".
3. Натисніть правою кнопкою миші або зайдіть у меню "Сервіс".
4. Оберіть пункт "Введення інформації з файлів Excel".
5. Вкажіть збережений файл `АВК_Матеріали.xlsx`.
6. Підтвердіть імпорт. Усі позиції з'являться в кошторисі з правильними шифрами, масою та цінами.
